# Aegis Test Repository

Dedicated small but architecturally meaningful test repository for Aegis Autonomous Agent validation.

## Structure
- `src/calculator.ts`: Core arithmetic functions (add, subtract)
- `src/greeting.ts`: User greeting logic
- `src/config.ts`: Configuration constants
- `src/utils/format.ts`: String formatting utilities
- `tests/calculator.test.ts`: Calculator test suite
- `tests/greeting.test.ts`: Greeting test suite
